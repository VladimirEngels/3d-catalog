# Оформление интерфейса

## Основные элементы

- Светлая и тёмная темы с настраиваемыми цветами.
- Плиточный и табличный виды каталога.
- Боковое меню с выбором команды и переходами между разделами.
- Панель фильтров и метки выбранных условий поиска.
- Выбор нескольких моделей и общие действия над ними.
- Тёмный фон превью и области 3D-просмотра.
- Цветовые обозначения состояний заданий и результатов проверок.

Настройки расположения меню, масштаба, размера плиток и анимации сохраняются
в браузере. Цвета задаются переменными CSS, которые изменяются при переключении темы.

## Шрифты и значки

Для основного текста используется IBM Plex Sans, для чисел и технических подписей —
IBM Plex Mono. Шрифты поставляются с приложением через пакеты `@fontsource`.
SVG-значки интерфейса находятся в `src/shared/ui/icons.ts`.

## Файлы оформления

| Путь | Содержимое |
|---|---|
| `src/shared/styles/tokens.css` | Цвета, размеры и переменные темы |
| `src/shared/styles/base.css` | Базовые стили страницы |
| `src/shared/styles/layout.css` | Общая раскладка интерфейса |
| `src/shared/styles/components.css` | Стили общих элементов |
| `src/modules/*/*.css` | Стили отдельных разделов |
| `mockups/*.html` | HTML-макеты экранов |
| `mockups/styles.css` | Стили макетов |
| `mockups/png/` | Изображения макетов |

Макеты хранятся отдельно от рабочих страниц; их внешний вид может отличаться
от текущего интерфейса. Демонстрационные результаты качества описаны
в [основном README](../README.md#текущее-состояние-и-ограничения).
