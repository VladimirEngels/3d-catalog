# Архитектура фронтенда

Многостраничный интерфейс на HTML, CSS и TypeScript. Vite используется для
разработки и сборки, Three.js — для отображения моделей и создания превью.

## Структура

| Путь | Назначение |
|---|---|
| `pages/` | HTML-страницы разделов |
| `src/modules/` | Код учётных записей, каталога, загрузки, заданий, качества и администрирования |
| `src/shared/api/` | HTTP-клиент, обработка ответов и общие типы |
| `src/shared/ui/` | Общие элементы интерфейса |
| `src/shared/styles/` | Стили, цвета и размеры |
| `src/shared/session.ts` | Состояние пользователя и выбранной команды |
| `src/shared/settings.ts` | Настройки внешнего вида |
| `public/site-settings.js` | Применение настроек до отображения страницы |
| `mockups/` | HTML-макеты и изображения экранов |
| `vite.config.ts` | Точки входа сборки, псевдонимы импортов и прокси API |

Внутри модулей `pages/` содержит код страниц, `components/` — элементы раздела,
`api.ts` — функции запросов, а CSS-файлы — стили модуля.

## Получение данных

1. HTML-страница подключает соответствующий TypeScript-модуль.
2. Код страницы собирает общий интерфейс и вызывает функции API своего модуля.
3. API получает данные сервера через общий HTTP-клиент.
4. Компоненты отображают полученные данные.

При разработке Vite передаёт запросы `/api/*` в Express на порту `3000`.
После сборки интерфейс из `frontend/dist/` раздаётся сервером Express.

## Права доступа

Интерфейс отображает действия с учётом роли пользователя.
Сервер независимо проверяет доступ при каждом защищённом запросе.

## Настройки

Тема, масштаб, положение меню, размер плиток, вид каталога и анимация
сохраняются в `localStorage` текущего браузера.
Скрипт `public/site-settings.js` применяет настройки до отображения страницы.
Цвета и размеры определяются переменными в `src/shared/styles/tokens.css`.
