# Оформление 3D Каталога

Здесь описан текущий интерфейс и расположение его стилей. Общая организация
проекта находится в [ARCHITECTURE](ARCHITECTURE.md), запуск — в [README](../README.md).
Пути указаны от корня проекта.

## Основные решения

| Элемент | Реализация и назначение |
|---|---|
| Навигация | Боковое меню, выбор команды и отдельные пункты владельца и администратора |
| Каталог | Плитки с превью или таблица; поиск, панель фильтров, метки выбранных условий |
| Несколько моделей | Выбор плиток и общая панель действий внизу страницы |
| Оформление | Светлая и тёмная темы, тёмное меню, зелёный акцент и светлый зелёный выбранный пункт по умолчанию |
| Поверхности и размеры | Линии, небольшие скругления, общие переменные размеров; тёмный фон превью и 3D |
| Качество | Зелёная плашка от 80%, жёлтая от 50%, красная ниже 50%; отсутствие оценки отображается отдельно |
| Задания | Состояния очереди, выполнения, готовности и ошибки; демонстрационные результаты подписаны |
| Графики | SVG-столбцы и полосы с подписями и подсказками; цвет берётся из текущей темы |

Интерфейс рассчитан на компьютер: ТЗ задаёт ширину от 1280 пикселей. В текущем
CSS минимальная ширина страницы равна `1240px / --site-scale`; это ограничение
ширины, а не мобильная адаптация.

Для текста используется IBM Plex Sans, для чисел и технических подписей —
IBM Plex Mono. Шрифты поставляются через установленные пакеты `@fontsource`,
поэтому после установки зависимостей приложению не нужен внешний сервис шрифтов.
Новые цвета интерфейса следует задавать через переменные темы.

## Настройки пользователя

[public/site-settings.js](../frontend/public/site-settings.js) подключается в HTML
до TypeScript-кода страницы и сразу применяет сохранённые настройки.
[shared/settings.ts](../frontend/src/shared/settings.ts) предоставляет к ним доступ
из TypeScript, [страница настроек](../frontend/src/modules/accounts/pages/settings.ts)
рисует элементы управления.

В `localStorage` сохраняются тема, масштаб, положение меню, размер плиток,
вид каталога, анимация, палитра и собственные цвета. По умолчанию меню справа;
его положение можно поменять. Настройки относятся к текущему браузеру и не
записываются в PostgreSQL.

Масштаб задаётся через CSS `zoom`; расчёты высоты и ширины используют
`--site-scale`. Координаты подсказок графиков учитывают масштаб через `getScale()`.
При изменении раскладки нужно проверять обе темы и масштабы 100% и 125%.

## Макеты экранов

[frontend/mockups](../frontend/mockups) содержит ранние HTML-макеты,
собственные `styles.css` и `charts.js`, а [mockups/png](../frontend/mockups/png) —
изображения для пояснительной записки. Эта папка не входит в рабочую сборку Vite;
внешний вид макетов может отличаться от приложения.

Например, `catalog-convert.png` и `catalog-team.png` показывают окна каталога,
`model-files.png`, `model-versions.png`, `model-textures.png` — вкладки карточки,
`upload-duplicate.png` — сообщение о повторной загрузке. Рабочие страницы находятся
в [frontend/pages](../frontend/pages).

Исправления действующего интерфейса нужно вносить в `frontend/src`, а не в CSS
макетов. Архивирование макетов запланировано отдельным этапом.
