# Конвертер OBJ и GLB

Самостоятельный JavaScript-модуль без внешних зависимостей. Входные и выходные
форматы — только OBJ и GLB. Загрузка других форматов в каталог выполняется отдельно.

## Устройство

- `index.js` — `convertFile`, проверка форматов и запуск преобразования.
- `readers/obj.js`, `mtl.js` — геометрия OBJ, материалы MTL и PNG/JPEG.
- `readers/gltf.js`, `gltf-data.js`, `gltf-material.js` — разбор GLB:
  GLB использует структуру glTF 2.0 внутри бинарного контейнера.
- `readers/files.js` — проверка путей и ограниченное чтение ресурсов модели.
- `writers/obj.js`, `glb.js` — запись результата.
- `core/` — проверка геометрии, материалы и матрицы преобразований.

## Вызов

```javascript
import { convertFile } from './converter/index.js';

const result = await convertFile('./input.obj', 'GLB', './output/new-model');
```

Выходная папка должна быть новой. Четвёртый необязательный аргумент задаёт корень
пакета ресурсов; по умолчанию это папка модели. Весь пакет ограничен 100 МБ.
Сетевые адреса и выход за пределы корня запрещены. Возвращаются `format`, `path`
и `losses` — предупреждения о потерях. Прямые экспортёры: `readObj`, `writeObj`, `writeGlb`.

OBJ с материалами и текстурами сервер выдаёт ZIP-архивом. Поддерживаются базовые
MTL (`Kd`, `d`, `Tr`, `map_Kd` без опций) и PNG/JPEG. GLB сохраняет базовые
PBR-материалы, UV0, цвета вершин и скелет с четырьмя влияниями на вершину.
При переводе в OBJ скелет фиксируется в статической позе; дополнительные карты,
PBR-параметры, тангенты и цвета вершин не переносятся. Потери перечисляются в `losses`.

Анимации не переносятся. Расширения glTF, морфинг и другие наборы UV вызывают отказ.
После записи результат повторно читается. Поле `quality` содержит показатели
`before`/`after` (вершины, треугольники, сетки, размеры, границы, UV, базовая текстура,
скелет), `losses`, `defects` и `needsReview`. Изменение треугольников или границ
с допуском 0,00001 от максимума между единицей и размером требует проверки.
Известные потери также помечаются для проверки. Число вершин и сеток показано
справочно: оно может меняться без изменения поверхности. Границы скелетной модели
рассчитываются в исходной статической позе.
Этот отчёт не сравнивает изображения и не рассчитывает процент визуальной похожести.

Сервер отдельно выполняет визуальное сравнение через Chromium и сохраняет снимки
с оценкой в отчёте операции. Сам модуль `converter` не зависит от браузерного движка.

Пятый необязательный аргумент `convertFile` — асинхронный обработчик массива геометрий.
Сервер использует его для замены базовых цветовых текстур перед записью результата.
Он возвращает массив геометрий; при отсутствии обработчика поведение прежнее.
Загрузка нейросети и сохранение изображений «до/после» находятся на стороне сервера.
